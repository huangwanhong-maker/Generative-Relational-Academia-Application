# Design pass records — the graph model specification

Raw output of the structured design pass behind [../spec-graph-model.md](../spec-graph-model.md).
Kept because this project is itself about recording how understanding changes — including its own.

| file | what it is |
|---|---|
| `draft-practice.md` | design from the working-researcher lens: occasions, materials, scenarios |
| `draft-architecture.md` | the component/action machinery, incl. the **kind-manifest sketch deferred from v1** (three worked examples: meeting, instrument calibration, dispute edge) |
| `draft-conformance.md` | 47-item feature gauntlet ruled against the constraints, + 12 audit findings on the skeleton |
| `verify-audit.json` | 17 constraint leaks found *in the drafts themselves* |
| `verify-missing.json` | 28 gaps; the load-bearing ones are answered in the spec §10 |
| `verify-cuts.json` | 22 cuts and the v1 kernel the spec adopted |

Where a draft and the specification disagree, the specification governs.
