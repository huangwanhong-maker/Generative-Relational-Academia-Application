## Current decision

After the migration, the project owner explicitly instructed that all four repositories use MIT and include contributor lists. The active repository licence, scope statement, README licence summaries, Python metadata and npm package declarations now implement that instruction. The new [CONTRIBUTORS.md](../CONTRIBUTORS.md) records the author and organizational credits found in the source notices and metadata. It does not invent additional contributors or a copyright assignment.

MIT applies as an additional grant for project-authored documentation and papers as well as code. It does not retract earlier permissions or silently rewrite historical terms. External works and user research records remain outside the project's grant. See [the current scope statement](../LICENSE.md) for redistribution of PDFs with preserved embedded notices.

The [dated machine-readable transition record](mit_transition_2026-09-22.json) lists the preserved notice hashes and unchanged PDF and bundle hashes. It is separate from the original import and relocation manifests, which continue to describe their own historical states. The original Git bundle and original external source checkout are unchanged.

The MIT text was checked against the [Open Source Initiative version](https://opensource.org/license/mit). The earlier AGPL text came from the [official GNU source](https://www.gnu.org/licenses/agpl-3.0.txt).
